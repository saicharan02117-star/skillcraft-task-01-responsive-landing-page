# SkillCraft Task 01 — Responsive 3D Landing Page

Orbit is a responsive career-platform landing-page concept created for SkillCraft Task 01. The project demonstrates an interactive fixed navigation menu that changes appearance after scrolling and provides visible hover feedback on every menu item.

## Task requirements completed

- Fixed navigation visible throughout the landing page
- Navigation style change after scrolling
- Animated hover and focus states
- Responsive desktop, tablet and mobile layouts
- Collapsible mobile navigation menu
- User-driven buttons and interactive roadmap demonstration
- Accessible labels, keyboard support and reduced-motion handling

## Technology

- Next.js 16 App Router
- React 19
- TypeScript
- CSS 3D transforms and animations
- Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```
